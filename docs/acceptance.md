## Объяснение фрагмента JavaScript (3.1)

Заказчик может выбрать любой фрагмент из `js/`. Короткие пояснения для самых вероятных:

**`analytics.js`, функция `track`:** копирует параметры в новый объект `data`, пропуская пустые; строки обрезает до 100 символов (правило GA4), числа и массив `items` оставляет как есть; в режиме отладки добавляет `debug_mode: true`; если передан `callback` (переход на thanks.html после заявки), вызывает его после отправки или через 1,2 с, если GA заблокирован; затем вызывает `gtag('event', имя, data)`.

**`analytics.js`, обработчик кликов:** один слушатель на весь документ; `closest('[data-event]')` находит кнопку или ссылку с атрибутом `data-event`, даже если нажали на текст внутри неё; для `view_item` собирает массив `items`, для остальных — берёт разрешённые `data-*` атрибуты и переводит их имена в snake_case (`data-button-name` → `button_name`).

**`prices.js`, функция `calc`:** вес берётся из таблицы по ширине, умножается на цену грамма металла и округляется; к нему прибавляются работа 3 500 ₽, цена камня и 1 200 ₽ за гравировку; цена пары — цена кольца × 2.

**`ring-size.js`, обработчик `submit`:** отменяет перезагрузку страницы; читает число (запятая заменяется на точку); по нити делит длину на 3,14, по кольцу берёт диаметр; `Math.round(x * 2) / 2` округляет до 0,5; отправляет `ring_size_calc`; если размер вне 14–23 — показывает предупреждение, иначе сохраняет размер в sessionStorage и подставляет его в ссылку на форму.

**`form.js`, отправка:** `preventDefault()` — без перезагрузки; `validate()` возвращает список ошибок, по каждой подсвечивается поле и отправляется `form_error`; данные собираются в объект и уходят `fetch` в Apps Script; кнопка на время отправки неактивна; при `ok: true` номер заявки сохраняется в sessionStorage, отправляется `generate_lead`, затем переход на thanks.html; при ошибке — `form_error` с `error_type = server`.

В папке находится PDF-файл с 12 скриншотами основных разделов проекта.

- [Открыть PDF со скриншотами](скриншоты.pdf)
- [Главная страница сайта](https://ogranka.vercel.app/)

Дополнительный скриншот GA4 из режима реального времени следует добавить отдельно, если он будет включён в комплект материалов к защите.

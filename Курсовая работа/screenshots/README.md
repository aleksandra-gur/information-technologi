# Скриншоты проекта «Огранка»

В этой папке размещаются подтверждающие материалы для курсовой работы:

- `01-home.png` — главная страница;
- `02-catalog.png` — каталог колец;
- `03-constructor.png` — конструктор;
- `04-engraving.png` — гравировка;
- `05-form.png` — форма заявки;
- `06-size.png` — подбор размера;
- `07-datalens.png` — дашборд DataLens;
- `08-leads.png` — Google Таблицы (без персональных данных клиентов);
- `09-telegram.png` — визуальный прототип Telegram;
- `10-mobile.png` — мобильная версия;
- `11-ga4.png` — Google Analytics 4, обзор в реальном времени.

Скриншоты следует добавлять в эту папку отдельными файлами. Персональные данные клиентов перед публикацией необходимо скрыть.

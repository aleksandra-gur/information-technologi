## Ограничения

- Раздел «Реклама» (пути к ключевым событиям) в России не заполняется: Google Реклама не подключается. Цепочку действий перед заявкой показывает обратный путь из 8.2.
- Данные — тестовые визиты Исполнителя, однокурсников и Заказчика, поэтому выборка маленькая и выводы предварительные.

## Подсказки к пунктам

- **User vs Traffic acquisition:** User acquisition считает пользователя по первому источнику (First user source), Traffic acquisition — каждый сеанс по его источнику (Session source). Если один человек сначала пришёл из Instagram, а потом напрямую, в User acquisition он один раз в instagram, а в Traffic acquisition — сеанс в instagram и сеанс в (direct).
- **Закрытая и открытая воронка:** в закрытой учитываются только те, кто прошёл шаги по порядку с первого; в открытой можно начать с любого шага, поэтому на последних шагах чисел больше или столько же.
- **Расхождение заявок и generate_lead:** блокировщики рекламы, отказ от cookie, заявка без JavaScript (ручная проверка приёмника через testDoPost), тестовые строки; generate_lead отправляется только после ответа `ok: true`.
- **Гипотеза:** должна проверяться изменением на сайте, например «если показать цену пары на карточке каталога, доля переходов из каталога в форму вырастет — проверим по воронке через неделю».

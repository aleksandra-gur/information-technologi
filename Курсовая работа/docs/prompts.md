# Использование нейросети в курсовом проекте

## Цель

Нейросеть использовалась как вспомогательный инструмент при подготовке документации и аналитических материалов для сайта ювелирной мастерской «Огранка».

## Примеры запросов

### 1. Документация GA4
Подготовить перечень событий Google Analytics 4 для сайта ювелирной мастерской, указать назначение событий и основные параметры.

### 2. Отчёт о тестировании
Оформить результаты проверок сайта, формы заявок и передачи UTM-меток. Разделить подтверждённые результаты и проверки, которые ещё необходимо выполнить.

### 3. README проекта
Подготовить README с адресом опубликованного сайта, идентификатором GA4, ссылками на документацию и текущим статусом приёмки.

## Ограничения

Сгенерированные материалы проверяются перед включением в проект. Описание события или проверки в документации не означает, что соответствующая функция реализована и успешно протестирована.

## Итог

Нейросеть использовалась для составления черновиков документации, структурирования тестовых результатов и оформления описания проекта.

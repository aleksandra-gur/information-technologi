# Техническая проверка курсового проекта

**Дата проверки:** 08.11.2026  
**Ветка:** `main`  
**Область:** исходники и структура репозитория. Внешние аккаунты GA4, Google Apps Script, Google Sheets, ManyChat и DataLens в рамках этой проверки не запускались.

## Что подтверждено по исходникам

| Компонент | Что найдено | Что это подтверждает |
|---|---|---|
| GA4 | Во всех 10 HTML-страницах подключён `gtag.js` с Measurement ID `G-37574R54DC` | Идентификатор и тег присутствуют в исходниках |
| События | `js/analytics.js` содержит общий метод отправки событий, обработчик `data-event` и режим `?debug_mode=1` | Клиентский механизм аналитики реализован в коде |
| Форма | `js/form.js` содержит непустой URL Apps Script, валидацию полей, UTM и POST-запрос | Форма настроена на отправку в указанный endpoint |
| Apps Script | `apps-script/Code.gs` содержит `doPost`, `doGet`, проверку данных, запись в лист `leads` и защиту от дубликатов | Серверная логика и схема записи подготовлены |
| Таблица | В коде указан Spreadsheet ID; описаны 14 столбцов и начальный статус `new` | Код знает целевую таблицу и структуру строки |
| Приёмка | `docs/acceptance.md` содержит 13 сценариев проверки | Подготовлен воспроизводимый план ручного тестирования |

## Что не подтверждено фактическим запуском

- Не получен ответ действующего Apps Script endpoint и не отправлена контрольная заявка из опубликованного сайта.
- Не проверено появление `generate_lead` в GA4 DebugView / Realtime.
- Не проверено совпадение заявок в Google Sheets с событиями GA4.
- Не проверены статусы заявок и обновление дашборда DataLens.
- Не подтверждён запуск двух сценариев ManyChat со второго аккаунта.
- Не добавлены скриншоты из GA4, DataLens и соцсетей; каталоги `screens/datalens`, `screens/explore` и `screens/instagram` содержат только служебные `.gitkeep`.
- В UTM-реестре есть 12 подготовленных строк, но ссылки на публикации и даты размещения не заполнены. Имена `anna_wedding` и `max_photo` помечены в комментариях как заменяемые на реальные ники партнёров.
- Аналитическая записка `docs/report.md` остаётся шаблоном без фактических чисел.

## Обязательная ручная проверка перед сдачей

1. Откройте URL Apps Script из `js/form.js` в браузере. Для `doGet` ожидается JSON с `ok: true` и `service: ogranka-leads`.
2. Откройте опубликованный сайт с параметром `?debug_mode=1`, отправьте одну тестовую заявку и проверьте строку в листе `leads`.
3. Убедитесь, что `generate_lead` появился в GA4 DebugView; сохраните снимки без персональных данных.
4. Повторите тест с тем же `request_id` через функцию `testDoPost`: повторная запись должна быть отклонена.
5. Проверьте изменение статуса заявки и соответствующее отображение в DataLens.
6. Проверьте ManyChat с другого аккаунта и сохраните доказательства обеих веток.
7. Внесите реальные URL и даты публикаций, затем заполните аналитическую записку по отчётам за явно указанный период.

**Вывод:** по репозиторию подтверждается готовность исходного кода и сценариев проверки. Производственная работоспособность внешних интеграций остаётся открытым пунктом до выполнения ручных тестов.

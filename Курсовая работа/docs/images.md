# Источники изображений

Все изображения сайта нарисованы программно скриптом на Python (библиотека Pillow) при создании сайта нейросетью Claude Opus 5.5. Фотографии и картинки из интернета не использовались, поэтому прав третьих лиц на изображения нет. Шрифты на картинках Open Graph — Georgia и Arial (системные шрифты Windows).

Формат — WebP (иллюстрации) и JPEG (Open Graph), каждое изображение меньше 300 КБ (самое большое — около 30 КБ). У каждого `<img>` на сайте заполнен `alt`.

| Файл | Что изображено | Где на сайте |
|---|---|---|
| `img/ring-R-01.webp` … `img/ring-R-18.webp` (640 × 480) | Кольцо модели R-01…R-18: металл, ширина, фактура, камень | Каталог, популярные модели на главной |
| `img/ring-R-01-lg.webp` … `img/ring-R-18-lg.webp` (1280 × 960) | То же крупно | Окно «Фото крупно» в каталоге |
| `img/hero.webp` | Пара обручальных колец из золота 585, у одного — бриллиант | Первый экран главной |
| `img/step-1.webp` | Кольца-образцы размеров 16–20 | «Как мы работаем»: примерка |
| `img/step-2.webp` | Восковая модель кольца | «Как мы работаем»: восковая модель |
| `img/step-3.webp` | Тигель и литьё золота в форму | «Как мы работаем»: литьё |
| `img/step-4.webp` | Футляр с парой колец | «Как мы работаем»: выдача |
| `img/workshop.webp` | Серебряное кольцо на ригеле и молоток | Мастер-класс |
| `img/engraving-ring.webp` | Внутренняя сторона золотого кольца | Гравировка, фон предпросмотра |
| `img/ring-size.webp` | Нить вокруг пальца и линейка | Как узнать размер |
| `img/og/og-*.jpg` (1200 × 630) | Название страницы, логотип, кольцо | Превью ссылок в соцсетях (`og:image`) |
| `favicon.svg`, `favicon-32.png`, `apple-touch-icon.png` | Кольцо с камнем на графитовом фоне | Значок сайта |

Скрипт, которым нарисованы изображения, хранится вне репозитория сайта (`tools/make_images.py`), чтобы в репозитории были только файлы сайта.
